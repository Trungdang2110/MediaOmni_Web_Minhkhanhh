# Field

Ô nhập liệu nền `paper-deep`, gạch chân đỏ rượu 2px như dòng kẻ trên giấy viết thư; dùng cho họ tên (có icon hồ sơ bên trái để mở danh sách hồ sơ đã lưu) và bộ ba ô ngày / tháng / năm.

- Nhãn phía trên, font `ui` 13px màu `ink-muted`.
- Lỗi: viền đổi sang `danger`, câu báo lỗi ngay dưới ô kèm icon — viết lịch sự, chỉ cách sửa ("Mời bạn kiểm tra lại").
- Các lỗi ngày sinh cần thiết kế: chưa nhập, ngày không tồn tại, ngày ở tương lai, năm trước 1900.
- Trên điện thoại ô ngày/tháng/năm vẫn nằm cùng một hàng.
