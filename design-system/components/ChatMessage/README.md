# ChatMessage

Tin nhắn trong trang Chat AI: người dùng là bong bóng xanh phấn bên phải; Pyra là "lá thư" nền `paper-deep` bên trái, có chữ ký "Pyra" font `caps` màu `claret`.

- Câu trả lời AI dùng font `text` (EB Garamond) 17px cho dễ đọc đoạn dài; hỗ trợ in đậm, danh sách, công thức.
- Nguồn tham khảo nằm cuối tin, ngăn bằng đường kẻ mảnh, chữ `ink-muted`.
- Trạng thái chờ: vòng xoay nhỏ màu `claret` + câu "Pyra đang tra cứu kho kiến thức…" rồi "đang viết câu trả lời…".
- Lỗi: tin nhắn kèm nút Ghost "Thử lại" ngay trong luồng hội thoại.
- Ngăn kéo lịch sử bên trái: nền `claret-deep`, chữ `on-claret`.
