# Notice

Thông báo ngắn (toast) nền `claret-deep` hiện 3 giây ở cuối màn hình, và nhãn tròn viền `gold` gắn cạnh nội dung.

- Toast dùng cho: lưu / xóa hồ sơ, nhập / xuất lịch sử chat, gửi khảo sát thành công.
- Nhãn dùng cho: "Đã lưu · còn 7 ngày" (nội dung AI lấy từ bộ nhớ), "Đã đủ 10 hồ sơ", trạng thái kết nối kho kiến thức.
- Luôn có chấm màu + chữ mô tả; chấm `success` = ổn, chấm `danger` = cần chú ý.
