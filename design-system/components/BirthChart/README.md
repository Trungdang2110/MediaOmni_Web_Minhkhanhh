# BirthChart

Biểu đồ ngày sinh dạng lưới 3×3 (hàng trên 3-6-9, giữa 2-5-8, dưới 1-4-7) đặt trong khung giấy viền vàng như một khung tranh nhỏ.

- Ô có số: nền `paper`, số lặp lại viết liền ("11", "222") màu `claret`.
- Ô vắng: viền nét đứt `line`, số mờ `ink-muted`.
- Ô thuộc mũi tên đủ số: thêm viền trong `gold`; danh sách mũi tên hiện bằng nhãn (tag) bên cạnh, chấm `success` = đủ, chấm `danger` = trống. Không chỉ dựa vào màu: luôn ghi chữ "đủ số" / "trống".
- Bấm vào ô để xem ý nghĩa con số; nút Ticket "Giải mã biểu đồ" mở phân tích AI (UC05).
- Thu gọn / mở bằng nút Ghost; trạng thái được trình duyệt ghi nhớ.
